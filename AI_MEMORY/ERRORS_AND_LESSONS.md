Восстановлено 07.11.2026 из `claude-migration/ERRORS_AND_LESSONS.md` и памяти. Не повторять.

## Методология (bybit)

1. Кластерный t по дням ≠ деньги трейдера: ~3900 тестов TRIALS.md, ни одна гипотеза не прошла «на сделку» и портфелем. Считать среднее на сделку + портфель с лимитом позиций.
2. Подгонка запрещена: FIT-прогон 1.43M комбинаций подтвердил FAIL на holdout.
3. Шорты «плохих» монет убивают редкие сквизы (+6500% COAI, +2800% ALPACA) — хвост лог-нормальный, выглядит как очевидная ставка, делает минус.
4. Стратегии, работающие на бумаге, в демо могут не совпадать — форварды и бумажные срезы обязательны.
5. CV-калибровка графических фигур LMW в крипте вырождается (h* на краю сетки у ~50% окон) — PAT не взлетел ещё на калибровке.

## Инфраструктура / ПК

6. Упавший процесс проверять через netstat/tasklist, не Get-Process по PID (чужие сессии не видны).
7. Логи писать Set-Content -Encoding UTF8, не *> (UTF-16 ломает чтение).
8. $pid — зарезервированная переменная PowerShell.
9. ISO-даты с дробной долей >6 знаков — парсить вручную (fromisoformat падает), усекать до 6, обрабатывать +00:00/Z.
10. .claude.json содержит дублирующиеся по регистру ключи путей — обычные JSON-парсеры падают; исходник не «чинить».
11. Headless ChromeWindow на Windows не даёт окно уже 500px — для мобильных скринов эмуляция viewport через puppeteer/playwright, иначе дезинформация (shots.mjs в rent-next — правильный образец).
12. mrkt_guard.json записался нулями при аварийном выключении ПК → бот ушёл в паузу. Лечение: open+flush+os.fsync перед os.replace (сделано 29.10).
13. Сканер лёг после пропадания питания без авто-восстановления (29.10) — watchdog/автозапуск до сих пор в планах, на ПК перезапуск вручную .bat-файлом.
14. News-сторожа (bybit news.py) сидели в одном try с run_pass — падали все разом при сбое RSS; разведены по отдельным try (13.10).
15. Если ПК/ноут спит — во всех форвардах/сканерах дыры (kpwatch 20 ч без строк + 51 «поздно»). Держать зарядку со сном «никогда» или VPS.
16. Код с ПК приходит на ноут с CRLF → sed с якорем $ не матчит; править через python/dos2unix.

## Торговля гифтами

17. ~62% алертов не покупаются в первые 10 минут — алерты опаздывают на 12 с, маркет реагирует за 0.3 с. Полный автобай по алертам проигрывает латентность.
18. Портфель врёт: проданные товары остаются в списке — баг учёта, чинить до доверия цифрам.
19. Моно-детектор ошибается на серых/бледных фонах — без калибровки по mono_labels.json и фильтра BEAUTY_MIN=90 не тратить.
20. Вход по коду Telegram на ноуте сломался (SendCodeUnavailableError после пустых Enter) — перелогин только по QR (login_qr.py, службу сначала остановить).
21. Тестовый бот в WSL пережил stop и слал ложные «MRKT пауза» — сначала проверять, КАКОЙ процесс шлёт сообщения.
