## Как пользоваться

- **Начало большой задачи:** прочитай `GLOBAL_MEMORY.md` (если задача не про rent-next) и файл проекта из `PROJECTS/<slug>.md`, плюс `TASKS.md` в корне рабочей папки проекта. **Для визуальной/дизайн-задачи — обязательно ещё `TASTE.md`** (правила вкуса из его референсов).
- **Память проекта** (факты, решения, архитектура) — здесь, в `PROJECTS/*.md`. **Что делать** — в `TASKS.md` в корне самого проекта. Не дублировать одно и то же в оба места.
- **Глубокий архив** полной памяти Claude Code: `C:\Users\stepa\Documents\deepseek-harness\default-workspace\claude-migration\` (детальные документы по 24 проектам, планы, оригиналы). Первоисточники: `C:\Users\stepa\.claude\` (список — в `SOURCE_INVENTORY.md`).

## Структура

| Файл | Что внутри |
|---|---|
| `GLOBAL_MEMORY.md` | Кто пользователь, стиль общения, правила работы, инструменты, референсы |
| `PROJECT_INDEX.md` | Все проекты: путь, статус, состояние, следующие задачи |
| `PROJECTS/<slug>.md` | Память отдельного проекта (архитектура, решения, баги, TODO) |
| `DECISIONS.md` | Принятые решения ✅ / рабочие ⚠ / отвергнутые ❌ |
| `ERRORS_AND_LESSONS.md` | Грабли, на которые уже наступали |
| `TIMELINE.md` | Хронология по датам |
| `TASTE.md` | Правила вкуса: дистилляция 100 референсов (approved.tsv) + directions.md + design-critic — палитры, шрифты, стоп-лист ИИ-лендинга |
| `WORKFLOW.md` | Ритуал обновления памяти (начало/конец сессии) |
| `SOURCE_INVENTORY.md` | Где лежат первоисточники (что откуда восстановлено) |
